# Code of Conduct

## Our Pledge
We pledge to foster a safe, respectful, and inclusive environment for all contributors.

## Standards
- Use welcoming, inclusive language
- Respect differing viewpoints
- Accept constructive feedback
- Focus on safety, clarity, and collaboration

## Enforcement
Report unacceptable behavior to the maintainers. All complaints will be reviewed and addressed promptly and fairly. Violations may result in removal from the project.

Instances of abusive, unsafe, or unacceptable behavior may be reported privately to the project maintainers.  
All complaints will be reviewed and addressed fairly and promptly.

Maintainers who fail to uphold this Code of Conduct may be removed from their roles.

## Reporting

To report a violation:
- Use GitHub’s private security advisory system, or  
- Contact the maintainer privately if listed in the repository profile  

Please avoid posting public issues for conduct or security concerns.

## Attribution

This Code of Conduct is adapted from widely used open‑source community guidelines, tailored to the safety‑critical nature of **Cognous Execution Runtime**.
