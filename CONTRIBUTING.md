# Contributing to Cognous Execution Runtime

Thank you for your interest in contributing! All contributions must reinforce safety, minimalism, and transparency.

## How to Contribute
- **Bug Reports**: Open an issue with clear steps to reproduce.
- **Feature Requests**: Propose features that do not expand agent capabilities without explicit permissioning.
- **Pull Requests**: Fork, branch, and submit a PR with tests and documentation.

## Code Style & Testing
- Keep code minimal, explicit, and auditable.
- Document all logic and permission checks.
- Add or update tests for every change.
- Never add implicit or default permissions.
- All actions must be permission-checked and logged.

## Permissioning Rules
- Update `permissions.json` only for explicit, reviewed changes.
- Never grant broad or wildcard permissions.

## Community
Be respectful and constructive. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
